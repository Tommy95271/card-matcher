# Agent Guidelines for 2026 Credit Card Matcher

Whenever you modify this codebase for features, fixes, or UI changes:

1. **Always Synchronize Changelog (`src/data/changelog.js`)**:
   - Add/update the entry at the top of `CHANGELOG_DATA` with the semantic version, release date, and highlight items (`feat`, `fix`, `ui`, `perf`).
2. **Always Synchronize `README.md`**:
   - Keep feature lists, directories, and architecture diagrams up to date.
3. **Always Synchronize `docs/development-journey.md`**:
   - Record significant design/architectural decisions in the ADR section.
4. **Follow Conventional Commits 1.0.0 Strictly**:
   - Use `feat(...)`, `fix(...)`, `docs(...)`, `style(...)`, `refactor(...)`, etc.
